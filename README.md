# trievol

Trievol is an independent digital services business operated by MD Ajharul Islam.

## Development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Before starting the server, copy `.env.example` to `.env` and set `GEMINI_API_KEY`. Keep real credentials out of Git.

Run the TypeScript check and production build:

```bash
npm run lint
npm run build
```
